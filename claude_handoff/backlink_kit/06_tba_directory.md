# Tennessee Bar Association (TBA) Directory

- **Platform:** Tennessee Bar Association (TBA) "Find a Lawyer" directory
- **URL:** https://www.tba.org/
- **Directory:** https://www.tba.org/page/findalawyer
- **Account type:** Membership-gated. The TBA "Find a Lawyer" directory is a benefit of TBA membership. Steve must be a current member.
- **Audience:** Other Tennessee attorneys (referral source); also a high-trust backlink

## Step-by-step

1. **Confirm TBA membership.** Check Steve's current membership status:
   - Log into https://www.tba.org/ with the email of record at the TN BPR.
   - If "Member since [year]" appears in the profile, membership is current.
   - If lapsed, renew via https://www.tba.org/page/membership (annual dues vary by years-since-bar-admission; for an attorney admitted in 2018, dues are roughly $250–$350/year as of writing — `[NEEDS VALUE FROM STEVE]` if exact).
2. Once membership is current, the directory profile is auto-populated from the TBA member-profile fields. Edit the profile, not a separate "directory" listing.
3. Navigate to **"My Profile"** → **"Edit profile"**.
4. Fill in the fields below.
5. Toggle the **"Include me in the public Find-a-Lawyer directory"** setting to ON.
6. Save. The directory updates within 24 hours.

## TN RPC 7.1 watch-outs

- TBA's directory category picker is short and uses generic labels ("Business," "Real Estate," "Civil Litigation") — none triggers RPC 7.1.
- TBA is run by the bar itself, so it does NOT permit "specialty" / "specialist" language — meaning the platform's own filters protect against accidental violations.
- The bio field is short (typically 1500-char limit). Use the trimmed bio below.

## Cost-benefit note

TBA membership is the main cost. The directory listing itself is
free-for-members. If Steve is not currently a TBA member, the
membership decision is a separate one — but if he IS planning to join
(or already a member), claiming the directory listing is essentially
free incremental work.

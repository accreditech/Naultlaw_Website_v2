(or fork into a spreadsheet if preferred — the markdown table is the
plain-text source of truth either way).

## Status legend

- **Not started** — no claim attempt yet
- **In progress** — application submitted, awaiting verification (postcard, phone call, BPR sync, etc.)
- **Verified** — profile claimed and ownership verified
- **Complete** — profile populated, photos uploaded, all fields filled
- **Live** — profile is publicly visible and indexed by search engines
- **Skipped** — Steve decided not to claim (note the reason)

## Recommended order

1. **Avvo + Justia first** (highest DA, fastest review, biggest backlink lift)
2. **FindLaw + Martindale next** (high DA; consumer-facing brand + lawyer-to-lawyer referral)
3. **TN Bar (#6) + TN BPR (#7)** (free / already paid; verify existing listings)
4. **GBP (#9) + Bing Places (#10)** (local-pack levers; free; **GBP is the single highest-leverage profile on this list**)
5. **LinkedIn personal (#11) + company (#12)** (separate from SEO but signals fund; medium-effort)
6. **BBB (#5) + Sumner Chamber (#8)** (paid; verify business value before paying dues)

## After each claim

When a profile goes live, update this file:

1. Change Status from `Not started` → `In progress` → `Live`
2. Paste the live profile URL into the third column
3. Note any platform-specific surprises in the "Notes" column

When the firm-side canonical facts change (new email, new phone, new
office), update `CANONICAL_FIRM_FACTS.md` FIRST, then re-sweep each
platform file to update the copy, then re-sync each live profile.

## Triage rules for non-listed platforms

Steve will see directory-claim invitations from many other platforms
(Lawyer.com, Lawyers.com, Lawyerlegion.com, Yelp Legal, Super Lawyers,
Best Lawyers in America, Lead Counsel, etc.).

**Default answer: not yet.** The 12 platforms above are the
high-leverage set. Adding more platforms before the high-leverage set
is complete is busywork. Once tier 1 + 2 are all Live, revisit and
decide whether additional listings are worth incremental claim-time.

**Paid-only platforms** (Super Lawyers, Best Lawyers in America,
Avvo Elite tier): defer until at least 12 months of active practice
data has accumulated. These platforms use peer-review or
firm-revenue-based criteria that take time to satisfy.

**Spammy "submission services"** (LawTrades, lawyer-directory.net,
etc.): skip entirely. Low DA, no traffic, often duplicate-content
penalties.

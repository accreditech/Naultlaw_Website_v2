# Bing Places for Business

- **Platform:** Bing Places for Business (Microsoft's local-business directory; equivalent of Google Business Profile for Bing Maps + Bing local search)
- **URL:** https://www.bingplaces.com/
- **Account type:** Free
- **Audience:** Bing Search + Bing Maps users (a smaller share than Google, but real); also feeds Yahoo (which uses Bing's index)
- **SEO value:** Modest direct traffic from Bing/Yahoo, but pairs naturally with the IndexNow integration (Task A / PR #23) for Bing-side SEO completeness

## Step-by-step

1. Visit https://www.bingplaces.com/ and sign in with a Microsoft account.
2. Bing Places offers an **"Import from Google Business Profile"** option — use it if the GBP profile (`09_google_business_profile.md`) is already live. Saves ~20 minutes of duplicate data entry.
3. If GBP isn't live yet, click **"Add a new business"** and fill in fields manually.
4. Verification options:
   - **Phone** (most common): Bing calls or texts the office number with a code.
   - **Mail**: Bing mails a postcard (similar to GBP).
   - **Bulk verification**: Multi-location businesses only — not applicable here.
5. Once verified, complete the fields below (same data as GBP, with minor format differences).

## TN RPC 7.1 watch-outs

- Bing Places' category picker uses **"Attorneys"** / **"Lawyers"** — compliant.
- Bing Places' description field is short (~250 chars). Use the trimmed bio below.
- Bing Places has less aggressive anti-keyword-stuffing enforcement than Google, but the same compliance language applies — RPC 7.1 governs regardless of where the bio is displayed.

## Photo specs

- Logo: 250×250 px PNG, transparent background preferred
- Cover photo: 1920×1080 px JPG (16:9)
- Profile photos: 800×600 px JPG. Bing accepts up to 100 photos.

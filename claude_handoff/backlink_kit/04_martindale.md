## Step-by-step

1. Visit https://www.martindale.com/claim-profile/ and search for "Stephen Nault" in Tennessee.
2. Click the existing stub (Martindale maintains profiles for all bar-admitted attorneys) → "Claim this profile."
3. Martindale verifies via the Tennessee BPR. Verification email comes to the bar's email of record.
4. Once verified, complete the profile fields below.
5. **Optional but valuable:** Martindale's "peer review" system asks other attorneys to rate the lawyer. Steve can ask 3–5 referring attorneys to leave reviews after the profile is live. This is the path to the "AV Preeminent" badge if Martindale's algorithm ever assigns one.

## TN RPC 7.1 watch-outs

- Martindale uses **"Practice areas"** — compliant phrasing.
- Martindale's algorithm assigns peer-rating badges (AV, BV, etc.). The lawyer doesn't claim these. Bio copy that says "AV Preeminent" or "Top-Rated" is fine ONLY if Martindale's algorithm has actually assigned the badge AND the lawyer is just stating the fact. Even then, RPC 7.1 Comment [3] cautions that comparative-claim language about ratings can mislead — safer to let the badge speak for itself in the sidebar and not mention it in the bio prose.
- Martindale's "Notable" / "Highlights" field accepts only objectively verifiable items. No "best in TN" claims.

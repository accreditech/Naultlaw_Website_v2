## Content-gap framework

For each thin page, target additions:

- **Tennessee-specific procedural detail** — code cites (Tenn. Code
  Ann. §§), filing venue, statute-of-limitations specifics,
  county-by-county nuance where relevant.
- **Typical engagement sequence** — day 1, week 1, deliverables.
- **Pricing and turnaround specifics** — flat-fee vs hourly, typical
  retainer size, typical turnaround range.
- **Concrete fact patterns** — 2–3 short anonymized scenarios that
  illustrate when this engagement is the right call. One paragraph each.
- **Scope fences** — explicit "what this is NOT" framing where useful
  (e.g., the real-estate pages already include not-a-closing-attorney
  language; preserve that pattern).

**What the writer should NOT add (TN RPC 7.1):**

- Outcome guarantees ("we will recover," "always wins," etc.).
- Specialization language ("specialist," "specialty," "specializes
  in," "specialization," "specialized") applied to the lawyer's
  practice.
- Comparative claims ("more experienced than other TN firms," "best
  in Tennessee").
- "Expert in [practice area]" (use "experienced in" or "focuses on").
- Named testimonials embedded in a service page (those belong on the
  homepage with source attribution).
